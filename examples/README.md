# Examples

- [p2p/](p2p/): node and gateway talking directly over LoRa P2P (temperature/humidity sensor example)
- [lorawan/](lorawan/): joining a LoRaWAN network (OTAA/ABP) and sending uplinks

Run every example from the repo root, e.g. `python examples/p2p/sensor_gateway.py`.
Settings come from `.env` (see the main [Readme](../Readme.md)).
